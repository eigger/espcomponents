# Approved UI source selections

Selected and approved on 2026-11-17. The dashboard now embeds custom composites
from these sources as `ui_*_terminal.wav`. Original MP3s are not republished.
See `ui_processing.json` for the actual excerpts, duration and processing.

Prefer short effects from one family so menu, success, and failure cues share
their timbre. RescopicSound's Modern Interface family is a candidate for the
phosphor terminal dashboard. The assignments below are editorial suggestions
based on the source descriptions; they are not hardware listening results.

| Dashboard event | Candidate | Suggested edit |
| --- | --- | --- |
| Click | [Select Small 01](https://pixabay.com/sound-effects/film-special-effects-ui-click-menu-modern-interface-select-small-01-230473/) | Keep a short transient; avoid a long tail on frequent presses |
| Menu open | [Window Open Small](https://pixabay.com/sound-effects/film-special-effects-ui-movement-menu-modern-interface-window-open-small-230486/) | Shorten to about 0.3–0.5 s |
| Menu close | [Window Close Small](https://pixabay.com/sound-effects/film-special-effects-ui-movement-menu-modern-interface-window-close-small-230483/) | Match the open cue's level and length |
| Success | [Confirm Small](https://pixabay.com/sound-effects/film-special-effects-ui-alert-menu-modern-interface-confirm-small-230482/) | Keep one confirmation phrase, about 0.4–0.7 s |
| Failure | [Deny Small](https://pixabay.com/sound-effects/film-special-effects-ui-alert-menu-modern-interface-deny-small-230476/) | One short rejection phrase; distinct from a persistent warning |
| Notice | [Pop Up Small](https://pixabay.com/sound-effects/film-special-effects-ui-alert-menu-modern-interface-pop-up-small-230480/) | A quieter single notification |
| Warning / danger | [Warning 01](https://pixabay.com/sound-effects/film-special-effects-ui-alert-alarm-modern-interface-warning-01-230492/) | Extract one complete pulse for caution and a short double pulse for danger; do not loop the full alarm |
